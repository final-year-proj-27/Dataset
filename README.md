# Lecture Video Dataset

## Overview

The **Lecture Video Dataset: Transcript-Dominant Summary-Assisted Semantic Indexing and Moment** is a research dataset published on [IEEE DataPort](https://ieee-dataport.org/documents/lecture-video-dataset-transcript-dominant-summary-assisted-semantic-indexing-and-moment).

The dataset is associated with our final-year project, which focuses on intelligent lecture video retrieval through transcript processing, summarization, semantic indexing, and context-aware moment retrieval.

It provides a dataset resource for research and development involving lecture content understanding and semantic video retrieval.

## Dataset Publication

- **Platform:** IEEE DataPort
- **Dataset:** Lecture Video Dataset: Transcript-Dominant Summary-Assisted Semantic Indexing and Moment
- **Publication Link:** [Access Dataset on IEEE DataPort](https://ieee-dataport.org/documents/lecture-video-dataset-transcript-dominant-summary-assisted-semantic-indexing-and-moment)

## Dataset Contents

The dataset is associated with the following research components:

- Lecture video data
- Lecture transcripts
- Dominant summaries
- Semantic indexing information
- Relevant video moments

*Refer to the IEEE DataPort record for the authoritative description, files, and dataset specifications.*

## Research Application

The dataset supports research into:

- Transcript-based lecture understanding
- Summary-assisted information retrieval
- Semantic search across lecture content
- Context-aware video moment retrieval
- Intelligent educational video navigation
